⚙ Configure Field Positions

Pick a field below, then tap where it should sit. Fields from the header show on page 1 of the real template; closing fields (totals, terms) show on page 2, since that's where they're printed. The item table fills as many page-1-style pages as needed before flowing onto the page-2 closing layout, so it holds up for both a 2-item and a 20-item order.
